Projetos Back-End

Bots para Discord

Um Bot no Discord, fundamentalmente, é um programa automatizado projetado para realizar diversas tarefas que enriquecem a experiência em servidores Discord. Esses bots atuam como assistentes virtuais, trazendo uma gama de funcionalidades que simplificam e dinamizam a administração e a interação dentro dos servidores.

PDV Parcial

Sistema para Ponto de Venda, de empresas de pequeno à médio porte. PDV é o local onde as transações comerciais ocorrem, seja em uma loja física, um site ou outro canal de vendas.

Fish Delivery

Um aplicativo de delivery de comida desenvolvido para praticar conceitos de front-end e back-end. O sistema permite que usuários naveguem por um cardápio digital interativo, escolham pratos, adicionem ao carrinho e finalizem o pedido.

Calculadora App

Aplicativo mobile desenvolvido para praticar conceitos de desenvolvimento Android, oferecendo operações matemáticas básicas por meio de uma interface simples e intuitiva. O sistema permite realizar cálculos de adição, subtração, multiplicação e divisão, proporcionando uma experiência prática para o aprendizado de componentes visuais, eventos e lógica de programação.

Carteirinha Digital

Aplicativo desenvolvido para facilitar a criação de carteirinhas digitais de identificação. O sistema permite capturar ou selecionar uma foto, inserir informações como nome, instituição e prontuário, e gerar automaticamente uma carteirinha pronta para visualização, compartilhamento ou impressão. O objetivo é oferecer uma solução prática e rápida para a emissão de identificações digitais em ambientes educacionais, corporativos ou institucionais.

Lista de Compras

Aplicativo de lista de compras criado para auxiliar usuários na organização de produtos para mercado e compras do dia a dia. O sistema permite adicionar, editar e remover itens da lista, facilitando o controle das compras e promovendo uma experiência simples e eficiente para o gerenciamento de tarefas domésticas.

App Clima

Aplicativo de previsão do tempo desenvolvido para consultar informações climáticas de forma rápida e acessível. O sistema exibe dados como temperatura, condições meteorológicas e previsões atualizadas, permitindo que os usuários acompanhem o clima de diferentes localidades por meio de uma interface moderna e intuitiva.

Academia App

Aplicativo fitness desenvolvido para academias e personal trainers, com foco no acompanhamento de treinos, evolução física e desempenho dos alunos. O sistema permite o gerenciamento de fichas de treino, acompanhamento de progresso, notificações, histórico de atividades e interação entre aluno e profissional, oferecendo uma experiência moderna e personalizada para o desenvolvimento físico e bem-estar dos usuários.
